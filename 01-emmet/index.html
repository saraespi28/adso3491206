01-Emmet

Plugin para codificación más rápida en HTML y CSS.

01-Child
Crea elementos hijos (anidación).

Ejemplo:

ul>li>a ↔

Resultado:

<ul> <li><a href=""></a></li> </ul>

02-Sibling
Crea elementos hermanos.

Ejemplo:

section+header+nav ↔

Resultado:

<section> <header></header> <nav></nav> </section>

03-Multiplication
Repite elementos varias veces.

Ejemplo:

ul>li*3 ↔

Resultado:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class
Crea un atributo de clase.

Ejemplo:

div.contenedor↔

.contenedor2↔

Resultado:

<div class="contenedor"></div> <div class="contenedor2"></div>

05-Classes
Crea múltiples atributos de clase.

Ejemplo:

div.clase1.clase2.clasen↔

Resultado:

<div class="clase1 clase2 clasen"></div>

06-Id
Crea un atributo de ID.

Ejemplo:

nav#menu ↔

Resultado:

<nav id="menu"></nav>

07-Text
Inserta contenido de texto.

Ejemplo:

div{Lorem Ipsum Dolor} ↔

a{Click Aquí} ↔

Resultado:

<div>Lorem Ipsum Dolor</div> <a href="">Click Aquí</a>

08-Custom Attribute
Crea atributos personalizados.

Ejemplo:

a[href=www.google.com] ↔

Resultado:

<a href="www.google.com"></a>

09-Item Numbering
Añade números consecutivos.

Ejemplo:

ul>li.num$*3 ↔

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering
Invierte el orden de numeración.

Ejemplo:

ul>li.num$*3 ↔

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering
Define un número base para secuencias

Ejemplo:

ul>li.num$@3*4 ↔️

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up
Sube un nivel.

Ejemplo:

section>article>div^p ↔️

Resultado:

<section> <article> <div></div> <p></p> </article>

13-Grouping
Agrupa elementos juntos.

Ejemplo:

(header>nav)+footer ↔️

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem
Genera texto de relleno.

Ejemplo:

lorem5 ↔️

Resultado:

<p>Lorem ipsum dolor sit amet.</p>

15-HTML Documents
Crea varios tipos de documentos HTML.

Ejemplo:

html:5 ↔️

Resultado:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>
